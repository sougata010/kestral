# Kestrel Browser — Developer Tools & Cybersecurity Intel Radar

## 1. Advanced Developer Suite (REQ-03)
- **Chrome DevTools Protocol (CDP) Stream**: Direct non-intrusive attachment to tabs to capture network timings and performance traces.
- **Technology & Framework Detection**: In-memory Wappalyzer heuristic scanner detecting React, Next.js, Vue, Tailwind, Vercel, and CDN edge providers.
- **Live Request/Response Topology**: Interactive canvas node topology and granular waterfall charts with DNS, TLS, TTFB, and download timings.
- **Utility Drawer**: Font inspector, CSS variable/color palette extractor, and 1-click cURL/Python/fetch export.

## 2. Cybersecurity Intel Radar (REQ-04)
- **Site Security Scorecard**: Instant audit of CSP, HSTS, cross-origin isolation, and TLS configuration.
- **Curated Security Tool Directory**: Searchable hub for top open-source tools (Ghidra, REA, Nuclei, Wireshark, etc.) with star counts and 1-click clone helpers.
- **Live CVE & Exploit Threat Stream**: Live feed of CISA KEV and NVD vulnerability notices matching detected technologies.
